# کنترل اصالت منابع سازنده

**فارسی** | [نسخه انگلیسی](README.en.md)

این پوشه امکان بررسی منشأ منابع سخت‌افزاری را فراهم می‌کند.

- <code dir="ltr">source_catalog.csv</code> برای هر منبع، مرجع صادرکننده، نوع منبع، محدوده کاربرد و دلیل استفاده در پروژه را ثبت می‌کند.
- <code dir="ltr">official_files_sha256.txt</code> شامل <code dir="ltr">SHA-256 hash</code> فایل‌های رسمی شرکت‌های سازنده است که به‌صورت محلی داخل پروژه نگه داشته شده‌اند.

فایل‌های میانبر <code dir="ltr">URL</code> عمداً <code dir="ltr">hash</code> نمی‌شوند، چون به صفحات زنده شرکت سازنده اشاره می‌کنند و ممکن است به‌روزرسانی شوند. فایل‌های <code dir="ltr">PDF</code> و تصاویر رسمی ذخیره‌شده به‌صورت محلی <code dir="ltr">hash</code> می‌شوند تا جایگزینی ناخواسته قابل تشخیص باشد.
