# Actual Project Board Photos

[فارسی](README.fa.md) | **English**

This folder is reserved for photos of the **exact ESP32-S3 N16R8 development board used in this project**.

Add clear front and back photos as:

- `Current_ESP32-S3_N16R8_Board_Front.jpg`
- `Current_ESP32-S3_N16R8_Board_Back.jpg`

These photos are intentionally separate from the official VCC-GND Studio images. Until the physical board is visually matched, the YD-ESP32-S3 V1.4 files remain a **candidate board reference**, not proof of the exact PCB manufacturer/revision in hand.
